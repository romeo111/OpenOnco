# OpenOnco

**Відкрита онкологічна база знань та інструменти для перевірюваного клінічного обговорення.** Рушій Python застосовує правила з версіонованої YAML-бази й формує альтернативні плани з джерелами. Мовна модель не обирає схеми лікування чи дози.

[Сайт українською](https://openonco.info/ukr/) · [English README](README.md) · [Документація](docs/README.md) · [Як долучитися](CONTRIBUTING.md)

Проєкт на ранній стадії: контент може бути неповним або очікувати клінічного рев’ю. Тести й посилання на джерела не означають клінічного схвалення. Лікар має перевірити результат за першоджерелами з урахуванням повної клінічної картини. Матеріали для пацієнтів допомагають підготувати питання до онколога.

## Стан бази знань

На **10 жовтня 2026 року**, за `python -m knowledge_base.stats --format json`: 103 хвороби, 831 показання, 404 схеми, 189 алгоритмів, 321 препарат, 257 біомаркерів, 671 сигнал ризику та 542 джерела. Це кількість сутностей, а не клінічно схвалених маршрутів. Окремо згенерований індекс сайту може мати інші цифри; перевіряйте [покриття](https://openonco.info/ukr/diseases.html) й статус рев’ю сутності.

Останній тегований реліз — [v0.1.3](https://github.com/romeo111/OpenOnco/releases/tag/v0.1.3). Сайт також містить пізніші зміни з `master`.

## Запуск і участь

Рекомендовано Python 3.12, як у CI. Команди встановлення, перегляду та MCP наведено в [English README](README.md); збірка й деплой — у [DEVELOPMENT.md](docs/DEVELOPMENT.md).

Перед зміною клінічних даних прочитайте [Charter](specs/CHARTER.md) та [стандарти контенту](specs/CLINICAL_CONTENT_STANDARDS.md). Англійські специфікації є канонічними; українські оригінали збережено в [specs/uk/](specs/uk/). Технічна перевірка не замінює клінічний підпис.
