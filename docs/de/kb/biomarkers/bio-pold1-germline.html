Anmerkungen

POLD1 Keimlinie (Exonuklease / Korrekturlesen-Domänenvarianten) — Antriebe Polymerase-Proofreading-Assoziierte Polyposis (PPAP), mechanistisch analog zu POLE-PPAP. Autosomal dominant; Oligopolypose + früh auftretender CRC + Endometrialkrebs (höhere Endometriumdurchdringung als POLE -PPAP). Tumore ultramutiert; potenzielle ICI-Empfindlichkeit. Überwachung: Koloskopie q1-2y von späten Teenagern; Endometrielle Probenahme von 40. STUB bis zur Zwei-Co-Lead-Abmeldung.
