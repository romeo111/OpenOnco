Anmerkungen

Two distinct biologies under one disease entity: HPV+ oropharyngeal: typically tonsil / base of tongue; younger patients; better prognosis; AJCC 8 separate staging system; active de-escalation trials (cisplatin-light or radiation-light protocols). HPV− (tobacco / alcohol): higher TP53 / CDKN2A mutation burden; worse prognosis; standard intensification. Therapy: - Localized: surgery (oral cavity preferred when feasible) ± adjuvant chemoRT; or concurrent cisplatin-RT (definitive); or induction + chemoRT (selected hypopharynx / larynx preservation). - Recurrent / metastatic 1L: * PD-L1 CPS ≥20: pembrolizumab monotherapy (KEYNOTE-048). * PD-L1 CPS ≥1: pembrolizumab + 5-FU + platinum (KEYNOTE-048 chemo-IO). * EXTREME (cetuximab + 5-FU + platinum) remains alternative. - 2L+: nivolumab (CheckMate-141) if IO-naive; cetuximab monotherapy / methotrexate / docetaxel. - Genotype-driven (investigational / accelerated): * HRAS mutant (~6-8%): tipifarnib (FDA breakthrough designation; AIM-HN phase 3 ongoing). * NTRK fusion (rare): larotrectinib / entrectinib. * BRAF V600E (very rare): dabrafenib + trametinib.
