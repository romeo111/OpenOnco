Anmerkungen

TNMB staging unique to MF (skin Tumor + Node + Metastasis + Blood involvement). Treatment fundamentally stage-based: skin-directed (topical steroids, NBUVB, PUVA, TSEBT) for early; systemic (mogamulizumab, brentuximab if CD30+, ECP, methotrexate, romidepsin, alemtuzumab) for advanced. Sézary syndrome variant always advanced. Out of Tier 1 detailed treatment scope for now — placeholder disease entity with skin-directed-then-systemic algorithm planned for next iteration.
