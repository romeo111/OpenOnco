Anmerkungen

Pleuropulmonary blastoma is the canonical DICER1-syndrome cancer — PPB diagnosis in any child should trigger DICER1 germline testing AND cascade-testing of parents + siblings. The Type I → Type II → Type III progression model is unique among pediatric cancers in offering a true surveillance-curable precursor lesion (Type I PPB is histologically benign-appearing cystic disease that, if completely resected, has excellent prognosis; if left in situ, may progress to the higher-mortality Type II/III). Treatment by type: Type I — complete surgical resection; close follow-up imaging for new cysts or solid transformation. Type II/III — surgical resection (often combined lobectomy / pneumonectomy with CNS prophylaxis consideration); IVADo (ifosfamide, vincristine, actinomycin-D, doxorubicin) or similar sarcoma-style regimens; CNS-directed therapy for Type III given high CNS-relapse risk.
