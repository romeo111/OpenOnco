Anmerkungen

Nur Germline — somatisch BRCA1/2 in der Brust fehlt die gleichen prospektiven RCT-Evidenz (verwenden Sie HRD-Test, wo Pfad-geänderten Status gesucht). Genetische Beratung zwingend (Kaskaden-Test von Erst-Grad-Verwandtschaft; Risiko-reduzierende Salpingo-oophorektomie). PALB2 hat analoge HRR-defiziente Biologie — neue Daten Unterstützung PARPi aber Off-Label. Toxizität: Zytopenien (~Grad 3 Anämie 16-25%), MDS / AML < 1,5% langfristig. Test vor Beginn eines PARPI-Kandidaten (Chemotherapie-Deeskalationsargument: Vermeiden Sie platinbasierte Sensibilisierungsregime, wenn PARPi leicht verfügbar ist).
