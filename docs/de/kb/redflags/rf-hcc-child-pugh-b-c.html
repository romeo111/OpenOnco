Ursprung der Roten Flagge

BegriffsbestimmungChild-Pugh B or C cirrhosis in HCC patient. CP-A is the only fully- studied class for ICI combinations (atezo+bev, durva+treme); CP-B has partial sorafenib/lenvatinib data but worse safety; CP-C generally precludes systemic therapy (focus on supportive care + transplant evaluation if liver-limited disease).

Anmerkungen

Kinder-Pugh-Score bewertet Enzephalopathie, Aszites, Bilirubin, Albumin, INR. CP-B: ICI-bev kontraindiziert (anti-angiogene Belastung der dekompensierten Leber); Sorafenib-Teildaten (GIDEON-Register). CP-C: beste unterstützende Versorgung + Hepatologie / Transplantation; systemische Chemo nicht indiziert.
