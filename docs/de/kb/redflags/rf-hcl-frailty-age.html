Anmerkungen

Die wöchentliche Trittfrequenz von Pentostatin erlaubt eine Anpassung zwischen den Dosen; die 5-7-Tage-Infusion von Cladribin wird durchgeführt. Für ältere Gebrechliche überwiegt die Verträglichkeit von Pentostan gegenüber der etwas höheren CR-Rate von Clatribin.
