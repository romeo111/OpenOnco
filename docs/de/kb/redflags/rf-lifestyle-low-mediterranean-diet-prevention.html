Ursprung der Roten Flagge

BegriffsbestimmungGeringe Einhaltung eines mediterranen Ernährungsmusters (Trichopoulou Mediterranean Diet Score [MDS] 0-3 von 9, oder PREDIMED-Stil punktet in der niedrigsten tertile, oder 14-item MEDAS <7). Mediterranes Ernährungsmuster = hohe Aufnahme von Olivenöl, Gemüse, Obst, Vollkorn, Hülsenfrüchte, Nüsse, Fisch; moderate Molkerei + Wein zu den Mahlzeiten; geringe Aufnahme von rotem/verarbeitetem Fleisch + Süßigkeiten. EPIC + Krankenschwestern-Gesundheitsstudie + PREDIMED-Kohorten: hohe Haftfähigkeit in Verbindung mit einer Verringerung der Gesamtkrebsinzidenz um 12-15% + Mortalität; stärkste Signale für SFB, Brust, Magen, Leberzellkarzinome + diätetische Vorteile für kardiovaskuläre Erkrankungen (PREDIMED 2013 RCT primärer Endpunkt). Mechanismen: hohe Polyphenol (Olivenöl, Gemüse) + θ-3 Fettsäure (Fisch) + Ballaststoffe + antioxidative Gehalt; geringe entzündungsfördernde rote / verarbeitetes Fleisch + raffinierte Kohlenhydratgehalt; günstige Mikrobiommodulation. Anmerkungen

Prevention-persona RedFlag für niedrige Mediterranean-Diät-Hypothese. Populations-Level diätetische-Muster Hebel – unterscheidet sich von ein-nährstoffigen RFs (Faser, Kalzium, rotes Fleisch). PREDMED RCT (2013 primärer Endpunkt Herz-Kreislauf; 2015 sekundäre CRC-Analyse) + EPIC + NHS Beobachtungssignal. Ankert an DIS-CRC, weil Musterkrebs Evidenz am stärksten ist dort; Multi-Krebs Nutzen in rationale gerahmt. Motorrouten zur PräventionPlanen Sie Ernährungs-Musterberatung + USPSTF-Kadenz-Screening pro Anker. STUB bis zur Zwei-Klinik-Co-Lead-Abmeldung per CHARTER §6.1 dev-mode.
