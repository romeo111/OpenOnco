Anmerkungen

STUB. Drafted for the DIS-PENILE-SCC Phase 1 authoring pass. MSI-H is rare in penile SCC and testing is not routine — this RF fires only when MSI/dMMR testing has actually been performed and returns positive. Mirrors RF-CRC-MSI-H-ACTIONABILITY's trigger/finding-key convention (finding: msi_status / dmmr_status) for consistency across the KB. Requires clinical co-lead signoff before publication (CHARTER §6.1; dev-mode-exempted for draft merge).
