Ein druckbarer Entwurf für das Arztgespräch

Plan Builder öffnet einen erstellten Entwurf im Druckdialog des Browsers. Ein erfundenes Beispiel zeigt, was vor dem Speichern als PDF zu prüfen ist.

von OpenOnco

Rückblickend verfasst; veröffentlicht am 2026-11-23.

Der englischsprachige Plan Builder zeigt neben dem erstellten Plan eine PDF-Schaltfläche zum Teilen. Sie öffnet für den Bericht den Druckdialog des Browsers; bietet der Browser Als PDF speichern an, kann dies dort gewählt werden. Der Klick speichert nicht automatisch eine PDF-Datei. Ein bequemes Übergabeformat ist keine klinische Freigabe des Entwurfs.

Stellen Sie sich ein eingebautes, erfundenes Beispiel zum diffusen großzelligen B-Zell-Lymphom vor. Erstellen Sie den vollständigen Plan, öffnen Sie den Bericht und prüfen Sie Quellenlinks, Warnungen und Prüfstatus. Nutzen Sie dann die PDF-Schaltfläche und kontrollieren Sie die Druckvorschau vor dem Speichern. Ändern Sie eine Eingabe, erstellen Sie den Plan erneut, damit der Druckentwurf zum aktuellen Beispiel passt. Die Seite ist nur für fiktive Fälle gedacht; geben Sie keine echten Patientendaten ein.

Der Plan ist ein Diskussionsentwurf und muss von einem qualifizierten Onkologen überprüft werden. Drucken belegt weder Genauigkeit noch klinische Validierung. Der Bericht wird im Browser vorbereitet; das Laden der öffentlichen Website-Dateien erfordert weiterhin Netzwerkzugriff, und die gespeicherte Datei bleibt auf Ihrem Gerät. Funktion, Code und öffentliche Seiten am 23. November 2026 geprüft. Dieser Artikel ersetzt keinen Arzt.
