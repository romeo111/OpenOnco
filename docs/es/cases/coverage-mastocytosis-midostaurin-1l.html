Qué NO hacer

Explicit prohibitive rules, each grounded in a regimen / supportive care / contraindication entity
Plan agresivo (IND-ADVSM-1L-MIDOSTAURIN)
  • NO use imatinib en el KIT D816V avanzado SM (resistencia intrinsica) — imainib está reservado para la rara neoplasia mieloide FIP1L1-PDGFRA con eosinofilia (entidad separada).
  • Do NOT continue midostaurin through gr ≥3 nausea/vomiting without antiemetic optimization + dose reduction (100 → 50 mg BID).
  • Do NOT start midostaurin without baseline ECG — QT prolongation requires electrolyte correction + monitoring.
Plan estándar (IND-ADVSM-1L-AVAPRITINIB)
  • NO use imatinib en el KIT D816V SM avanzado — resistencia intrínseca ( choque esterico).
  • Do NOT start avapritinib with platelets <50 ×10⁹/L — boxed warning; switch to midostaurin (alternative indication).
  • NO use avapritinib como monoterapia para el SM-AHN: el componente AHN (MDS/CML/AML) necesita su propio tratamiento histológico.
  • NO se salte la RMN cerebral basal: la vigilancia cerebral con microsangulos forma parte del programa de monitorización.
