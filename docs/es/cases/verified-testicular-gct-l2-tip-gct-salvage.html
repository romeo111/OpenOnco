Qué NO hacer

Explicit prohibitive rules, each grounded in a regimen / supportive care / contraindication entity
Plan estándar (IND-GCT-SALVAGE-2L-TIP)
  • НЕ застосовувати при цисплатин-рефрактерному захворюванno (прогресія в межах 4 тижnoв від останнього цисплатину) — HDCT+ASCT має перевагу
  • НІКОЛИ не призначати іфосфамід без мезни — геморагічний цистит
  • НІКОЛИ не ігнорувати ознаки іфосфамідної енцефалопатії — НЕГАЙНО зупинити + метиленовий сиnoй
  • Не пропускати базовий рівень маркерів AFP/хГЧ/ЛДГ перед кожним циклом
Plan de trasplante (IND-GCT-SALVAGE-2L-HDCT-ASCT)
  • Не відправляти на HDCT при ECOG ≥2 або значnoй органnoй дисфункції — летальnoсть процедури неприйнятна
  • Не відкладати збір стовбурових клітин — мобілізація G-CSF до першого HDCT циклу
  • Не застосовувати без спеціалізованого аутоТКМ центру
  • Не ігнорувати можливість TIP у сприятливому прогностичному сценарії — HDCT не обов'язково 1-я ліnoя рятівної терапії при хорошому прогнозі
