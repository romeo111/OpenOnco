Notas

Encuentro de vocabulario compuesto para marcadores de linaje diagnóstico y diferenciación IHC. Estos marcadores apoyan histogénesis, lugar de origen, inmunofenotipo de linfoma, diferenciación neuroendocrina, linage de melanoma, lignée mesotelial, lignage de sarcoma y diferenciacion gérmica. Deben ser aceptados mediante análisis de casos de texto libre como contexto de biopsia, pero no deben interpretarse como accionabilidad de nivel de variante o solos para seleccionar terapia sistémica dirigida.
