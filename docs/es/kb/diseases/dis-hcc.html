Notas

El CHC es el arquetipo canónico "híbrido": el estadio BCLC impulsa la modalidad cascada (resección / trasplante / ablación para 0-A; TACE / TARE para B; sistémico para C; apoyo para D), Y factores etiológicos rigen las decisiones paralelas (profilaxia del VHB sobre IC/quimioterapiaTACE; tratamiento del VHC y enlace para RVS; estilo de vida MASH; cesación del alcohol). La clase Child-Pugh es el modificador universal — cada estadio del CHC tiene un CP-A vs CP-B vs subdivisión CP-C, y el CP- C generalmente impide la terapia sistémica. Esto compromete la lógica sistémica-solo-terapia (BCLC C, CP-A) - las modalidades curativas (cirugía, trasplante, ablación) esperan la ratificación de la PROPUESTA §17. La enfermedad está por lo tanto marcada "parcial".
