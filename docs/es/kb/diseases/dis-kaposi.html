Notas

Cuatro formas epidemiológicas (clásicos / endémicos / iatrogénicos / relacionados con el SIDA) comparten HHV-8 como etiología obligatoria. Tratamiento: restauración inmune primero (ART para el SIDA-KS; reequilibrio de la inmunosupresión para iatrogónico - conversión mTOR- inhibidor tiene actividad directa anti-Kaposi); quimioterapia sistémica (doxorrubicina liposómica / paclitaxel) para enfermedad sintomática / visceral. La enfermedad multicéntrica de Castleman (MCD) impulsada por KSHV y el linfoma primario de derrame (PEL) están relacionadas pero distintas.
