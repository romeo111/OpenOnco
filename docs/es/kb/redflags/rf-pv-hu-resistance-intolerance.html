Notas

En el ensayo RESPONSE se estableció ruxolitinib como 2L para el PV resistente/intolerante a HU (Hct + endpoint primario compuesto de volumen de bazo 21% vs 1%). NO se aplica como 1L (sin beneficio probado de SG sobre HU). El interferón-α pegilado (ropeginterferón) es una alternativa 2L/preferido para el fotovoltaico más joven, pero limitado al acceso.
