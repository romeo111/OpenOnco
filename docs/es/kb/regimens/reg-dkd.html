Notas

CANDOR trial (Dimopoulos 2020): in r/r MM after 1-3 prior lines, DKd (KdW-like schedule) vs Kd alone improved mPFS (28.6 vs 15.2 mo, HR 0.59); 2-year PFS ~62% vs 41%. Provides effective PI-switch + anti-CD38 add-on for patients progressing on bortezomib-based 1L (VRd or D-VRd). Particularly useful when bortezomib neuropathy precludes PI re-challenge. Cardiac toxicity is the key safety signal; baseline + serial ECHO + BP monitoring mandatory. Isatuximab + carfilzomib + dex (Isa-Kd, IKEMA trial) is a near-equivalent alternative — separate Regimen entity if isatuximab access available. KRd (carfilzomib + lenalidomide + dex, ASPIRE trial) is the alternative if patient is len-naive AND PI-naive in earlier line.
