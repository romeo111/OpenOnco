Notas

1L for MDS-LR symptomatic anemia if endogenous EPO ≤500 mU/mL AND RBC TD ≤2U/month — response rate ~50-60% in this selected population. Add G-CSF in non-responders if RS-MDS subtype. Target Hb 10-12 g/dL (do NOT exceed). Switch to luspatercept (MEDALIST: RS-MDS post-ESA; COMMANDS: 1L LR-MDS broadly) or lenalidomide (del 5q) on failure. STUB — requires clinical co-lead signoff before publication.
