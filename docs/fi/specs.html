Eritelmät

OpenOnco on ensimmäinen spesifikaatioprojekti, jonka jokainen arkkitehtoninen, kliininen ja hallintoon liittyvä yksityiskohta on merkitty markdown-asiakirjaan alla. specs/ that is versioned and open to public review. 10 active specifications cover everything from FDA non-device CDS positioning to the shape of every YAML entity in the KB. The full text lives at github.com/romeo111/OpenOnco/spekts.

Totuushierarkian lähde (CLAUDE.Md:ltä): kun spesifikaatiot ovat ristiriidassa, sitova määräys on 1. Charter.md → 2. muut specs/*.md → 3. CLAUDE.md → 4. LUEME.Md. Kaikki alla legacy/ ei ole arvovaltainen.

Aktiiviset vaatimukset (10)

Hallinnointi CHARTER.md

Peruskirja ja hallintotapa

Project governance, scope (what it does and what it explicitly does not), FDA non-device CDS positioning (§15 with constraints C1-C7), the solo-maintainer workflow for source-traceable content (§6.1), patient-data privacy (§9.3), forbidden prompt patterns for LLMs (§8.3 — LLMs do not make clinical decisions).

Kliiniset tutkimukset CLINICAL_CONTENT_STANDARDS.md

Kliinistä sisältöä koskevat vaatimukset

Clinical content standards: citation format (source_id + position + paraphrase + page), evidence-level taxonomy (Tier 1-6), reviewer sign-off workflow, STUB → reviewed transition criteria. Every claim in an Indication / Regimen / RedFlag links to a Source entity.

Tiedot DATA_STANDARDS.md

Tietostandardit – potilasmalli

Patient profile data model. FHIR R4/R5 + mCODE alignment on the roadmap. Code systems: LOINC + ICD-10/O-3 + RxNorm + CTCAE v5.0. No SNOMED CT and no MedDRA in the MVP (license gates). Profile fields and semantic interoperability.

Tietohermoston erittely

Pydantic schemas for every KB entity — Disease / Indication / Regimen / Algorithm / Biomarker / Drug / Test / Workup / RedFlag / Contraindication / MonitoringSchedule / SupportiveCare / Source. Defines fields, validators, referential-integrity rules, and the migration roadmap to PostgreSQL.

Miten päivitämme spesifikaatiot

Yksi ylläpitäjistä toimittaa päivityksiä automaattisella tarkastuksella ja lähteen jäljityksellä. Ulkoinen kliininen arviointi on valinnainen ja se kirjataan erikseen.

Kaikki tiedot on kirjoitettu ukrainalaisesti (rajapinta ja kliiniset arvioijat ovat UA), mutta tekniset termit ja lisenssinimet pysyvät englanninkielisinä. Versiointi on kautta git: every spec cards v0.1 (draft) Otsikkoon ja se on törmätty pieniin/suuriin, riippuen murroksesta.
