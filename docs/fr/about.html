OpenOnco

À propos d’OpenOnco

OpenOnco est un projet de connaissances cliniques et de règles ouvertes pour l'oncologie. Cette page recueille le matériel qui a utilisé pour s'asseoir dans des liens de haut de menu séparés: exemples, spécifications et GitHub.

Notre objectif

Faciliter la compréhension des décisions cliniques complexes

Le traitement du cancer a rarement une réponse évidente. Les cliniciens doivent tenir compte du diagnostic, de l'état, des biomarqueurs, du traitement antérieur et des risques.

OpenOnco vise à rendre ce processus visible : montrer des chemins possibles côte à côte, expliquer ce qui influence le choix et le lien avec les sources. Il soutient la préparation et la discussion, plutôt que de prescrire automatiquement le traitement.

Une règle simple

Une revendication doit être traçable à une règle et à une source avant de pouvoir faire partie d'un plan.

Notre démarche

Un processus reproductible pour préparer une conversation avec un clinicien

01

Structurer le contexte clinique

Le profil décrit les faits pertinents à la décision : type de tumeur, stade, biomarqueurs, état général et traitement antérieur.

02

Comparez-le avec les règles et les sources

Les règles utilisent une base de connaissances versionnée. Elles expliquent pourquoi une option est envisagée, sans deviner un médicament ou une dose.

03

Résultats actuels qui peuvent être vérifiés

Les utilisateurs voient les options côte à côte, les avertissements et les liens vers les sources originales, pour préparer des questions pour un carton tumoral ou oncologue.

Le travail derrière elle

L'effort principal consiste à soutenir les résultats

Une base de connaissances structurée

L'équipe enregistre les maladies, les régimes, les indications, les avertissements et les sources en tant qu'entités liées distinctes. Les changements peuvent ensuite être modifiés et vérifiés, plutôt que de se perdre dans les paragraphes.

Traçabilité à chaque étape

Les allégations cliniques ont enregistré la provenance. Les règles, les résultats et les exemples publics peuvent être inspectés plutôt que pris en confiance.

La sécurité définit les limites

The system does not replace diagnosis, handle emergencies, calculate personalised doses or make decisions on behalf of a clinician.

Forme du projet

Ouvrir par défaut

Le code est de type MIT; les spécifications et le contenu généré sont CC BY 4.0.

Données publiques synthétiques

The public site ships no real patient records and no patient-specific private artifacts.

Contrôle clinique

Le contenu clinique doit être approuvé par l'examinateur avant qu'il ne puisse devenir un contenu fiable.

Automatisation auditable

Les règles, les sources et le raisonnement rendu sont visibles au lieu de se cacher derrière une boîte noire.
