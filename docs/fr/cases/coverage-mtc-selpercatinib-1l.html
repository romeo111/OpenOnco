Ce qu'il ne faut pas faire

Explicit prohibitive rules, each grounded in a regimen / supportive care / contraindication entity
Standard plan (IND-MTC-ADVANCED-1L-SELPERCATINIB)
  • Ne commencez PAS le traitement systémique avec la calcitonine MTC asymptomatique, structurellement stable et à élévation lente — observez avec la calcitonine / CEA q3-6 mo + imagerie q6-12 mo.
  • N'utilisez PAS d'iode radioactif (IRA) dans le MTC — les cellules C parafoliculaires ne concentrent pas l'iodure; l'IRA n'a aucune efficacité.
  • Ne pas sauter les tests de RET germinatif — ~25% du MTC est héréditaire; les moteurs germinatifs positifs sont des tests de dépistage génésique + surveillance du phéochromocytome + synchronisation prophylactique-thyroïdiectomie chez les descendants.
