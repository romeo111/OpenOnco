Résumé des faitsHGBL avec MYC + BCL2 (et/ou BCL6) réarrangements ('double-hit' / 'triple-hist') a une trajectoire agressive avec R-CHOP sous-cure. DA- EPOCH-R (Petrich JCO 2014; Dunleavy Blood 2018) montre un CR/PFS supérieur dans une série à bras unique. Pola-R-CHP (POLARIX, Tilly NEJM 2022) approuvé pour DLBCL — DH analyse sous-groupe numériquement favorable. CAR-T (axi-cel, liso-cel) efficace à 2L+.

Notes

ESCAT IIA. CNS prophylaxis recommended. MYC-only rearrangement (single-hit) treated as DLBCL-NOS.
