Notes

Groupes à risque : 0-1 faible (10y OS ~70%); 2 int (~50%); ≥3 élevé (~35%). FLIPI2 intègre Hb + β2M + LDH + moelle osseuse + diamètre de masse le plus long — légèrement mieux discriminatoire mais utilisé moins fréquemment. stratification informative pour conseils pronostic; ne dirige pas directement le choix de traitement 1L (les critères GELF le font).
