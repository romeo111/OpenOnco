Notes

Le MET ex14 se présente dans ~3–4% de l'adénocarcinome NSCLC; enrichi chez les patients âgés, histologie sarcomatoïde. Le capmatinib (GEOMETRY mono-1) et le tepotinib sont approuvés pour le NSCCL avancé ex14 positif. L'amplification MET de haut niveau (GCN ≥10) est un sous-ensemble de HCC et RCC papillaire et est un mécanisme de résistance actionable dans le NCSLC mutant EGFR progressant sur osimertinib( osimmertinib combiné + savolitinib dans les essais).
