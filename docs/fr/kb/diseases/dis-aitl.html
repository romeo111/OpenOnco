Capacités

Notes

CD30 positif en ~40-50% — éligible pour le brentuximab-CHP. Les lymphomes secondaires de cellules B dirigés par EBV peuvent se développer pendant l'ITL — considération distincte. Hypogammaglobulinémie + cytopénies auto-immunes fréquentes.
