Notes

Scaffolded for batch #2: 4 RFs (intracranial-pressure emergency, MGMT-actionability, frailty/age — elderly Stupp-modified, biopsy-only vs maximal-safe-resection MDT-trigger). 1 regimen (TMZ Stupp concurrent + adjuvant). 2 indications (Stupp full for fit; TMZ-only for elderly unmethylated unfit). 1 algorithm. Lineage value `carcinoma` is suboptimal — neuroepithelial would be more accurate. Schema's lineage field is free-text Optional; using `carcinoma` for now to match other solid-tumor entries; clinical authors may want to add `glioma` / `neuroepithelial` enum value in future. RT 60 Gy / 30 fractions concurrent with TMZ 75 mg/m²/d daily during RT is the canonical Stupp concurrent phase. RT NOT modellable per PROPOSAL §17 — treated as free-text in Indication.notes for now.
