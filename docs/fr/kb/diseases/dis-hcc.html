Notes

Le HCC est l'archétype « hybride » canonique : le stade BCLC conduit la cascade de la modalité (resection / greffe / ablation pour 0-A; TACE / TARE pour B; systémique pour C; soutien pour D), ET les facteurs étiologiques régissent les décisions parallèles (prophylaxie du HBV sur ICI / chimioTACE; traitement du VHC et liaison pour SVR; mode de vie MASH; arrêt de l'alcool). La classe Child-Pugh est le modificateur universel — chaque stade B CLC a un CP-A vs CP-B vs subdivision CP-C, et le CP- C exclut généralement la thérapie systémique. Cette approche implique une logique systémique-thérapie-seulement (BCLC C, CP-A) - les modalités curatives (chirurgie, transplantation, ablation) attendent la ratification de la PROPOSITION §17. La maladie est donc marquée par une «partielle».
