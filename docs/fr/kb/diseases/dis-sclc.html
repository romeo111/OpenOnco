Notes

La fourchette dominante est l'archétype: stage_driven — limitée vs étendue. Époque moderne: combinaisons chimioimmunothérapie standard pour extensive; chimio + RT concurrente pour limitée. Options ciblées/biomarqueurs (par exemple tarlatamab ciblé DLL3 pour extensif 2L+) émergent mais pas encore 1L standard.
