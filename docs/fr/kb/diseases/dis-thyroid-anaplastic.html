Notes

Among the most lethal solid tumors historically — IVC by AJCC at diagnosis (any T any N M0/M1 = stage IVA/B/C). Median OS without targeted therapy 3-6 months; rapid airway compromise common. Time-critical workup: BRAF V600E status drives first-line systemic therapy and must be available within days, not weeks. ATA 2021 guideline mandates rapid IHC (VE1 antibody) + reflex sequencing. Therapy by genotype: - BRAF V600E mutant (~25–40%): dabrafenib + trametinib (ROAR basket trial — ORR ~56%, transformative); FDA approved 2018 for ATC. Often used as neoadjuvant induction → surgery → adjuvant chemoRT. - BRAF wild-type RAS / NTRK / RET targetable: selpercatinib / pralsetinib / larotrectinib / entrectinib per genotype. - BRAF/RAS/NTRK/RET wild-type: chemo-radiation (paclitaxel + RT or docetaxel + doxorubicin + RT); pembrolizumab if PD-L1+ or TMB-H. Tracheostomy decision is patient-/family-driven; some protocols defer to systemic-therapy response over upfront tracheostomy when BRAF-mutant.
