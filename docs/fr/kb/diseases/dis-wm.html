Notes

Only NHL with defining "must-have" mutation (MYD88 L265P) — strongly predicts BTKi response. CXCR4 status affects BTKi depth of response (WT > WHIM-mutated). Hyperviscosity emergency requires plasmapheresis before any cytotoxic therapy.
