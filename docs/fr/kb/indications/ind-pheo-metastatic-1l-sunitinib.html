Coverage-enabling metastatic-disease indication for DIS-PHEOCHROMOCYTOMA, default non-MIBG-avid systemic branch (FIRSTMAPPP evidence). Reuses DRUG-SUNITINIB. expected_outcomes uses OutcomeValue wrappers pointing at SRC-FIRSTMAPPP-BAUDIN-2024; the file under independent review had cited this trial under a 2023 year-suffix id with null DOI/PMID and had deliberately omitted the effect size out of an abundance of caution -- this session independently confirmed the trial via PubMed (PMID 38402886; Lancet 2024;403(10431):1061-1070) and corrected the source id/year and populated the verified 12-month PFS figures (36% vs 19%) rather than leaving them unstated. Requires medical oncology co-lead signoff before clinical publication.
