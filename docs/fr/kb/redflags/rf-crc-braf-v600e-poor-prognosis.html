Origine du drapeau rouge

DéfinitionLa mutation BRAF V600E dans le mCRC : prévalence de ~8-10%, mauvais pronostic (SG médiane diminuée de moitié par rapport à BRAF-WT sur la chimiothérapie standard). Cetuximab/panitumumab inefficace. Encorafenib + cetuximab (BEACON CRC) est préféré 2L+; quelques données 1L favorisent FOLFOXIRI + intensification bev dans le MSS BRAF-mutant.

Notes

~30% of BRAF-mutant CRC are MSI-H — RF-CRC-MSI-H-ACTIONABILITY takes precedence (immunotherapy-track outranks chemo-intensification). In MSS BRAF-V600E mutants (the harder subgroup), TRIBE-2 / FOLFOXIRI+bev has ORR 56% but inferior to immunotherapy combinations under study.
