Notes

BEACON CRC trial: BRAF V600E mCRC 2L+ — encorafenib + cetuximab doubled mOS vs control (9.3 vs 5.9 mo). NCCN cat 1 + ESMO strong recommendation for this molecular subtype. Triplet arm (+binimetinib) showed no OS benefit over doublet — doublet is current standard. Skin surveillance critical (new SCC class effect of all BRAFi).
