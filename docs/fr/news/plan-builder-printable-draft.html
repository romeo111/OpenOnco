Un brouillon imprimable pour échanger avec le médecin

Plan Builder ouvre un brouillon généré dans la boîte de dialogue d’impression du navigateur. Un exemple fictif montre quoi vérifier avant de sauvegarder un PDF.

par OpenOnco

Rédigé rétrospectivement ; publié le 2026-11-23.

Le Plan Builder, disponible en anglais, propose un bouton PDF à côté du plan généré. Il ouvre la boîte de dialogue d’impression du navigateur pour le rapport ; si Enregistrer au format PDF est proposé, vous pouvez le choisir. Le clic n’enregistre pas automatiquement un PDF. Un format pratique à transmettre n’est pas une approbation clinique du brouillon.

Imaginez sélectionner un exemple intégré et fictif de lymphome diffus à grandes cellules B. Générez le plan complet, ouvrez le rapport et examinez les liens vers les sources, les avertissements et l’état de révision. Utilisez ensuite le bouton PDF et vérifiez l’aperçu avant de sauvegarder. Si vous modifiez une donnée, régénérez le plan pour que le brouillon imprimé corresponde à l’exemple actuel. La page est réservée aux cas fictifs ; ne saisissez pas de données de vrais patients.

Le plan est un brouillon de discussion qui doit être vérifié par un oncologue qualifié. L’impression ne prouve ni l’exactitude ni une validation clinique. Le rapport est préparé dans le navigateur ; le chargement des ressources publiques du site utilise toujours le réseau et le fichier enregistré reste sur votre appareil. Fonction, code et pages publiques vérifiés le 23 novembre 2026. Cet article ne remplace pas un médecin.
