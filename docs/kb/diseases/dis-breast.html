Capabilities

Notes

Single Disease entity with biomarker_driven archetype — receptor subtype (ER/PR/HER2) and BRCA/HRR status are the dominant Algorithm branch points. Sub-strata (early vs metastatic) carried as Indication applicable_to.stage_requirements. Decision: ONE Disease (not three) chosen because: (1) shared diagnostic workup, biomarker testing, surgical paradigm; (2) shared bone-health, fertility-preservation, psychosocial supportive care; (3) treatment branching is uniformly resolved through biomarker findings + Algorithm decision_tree — no need for separate Disease entities. Male breast cancer follows the same algorithm with gender-specific notes in supportive care + treatment-tolerance considerations.
