OpenOnco

Sobre o OpenOnco

OpenOnco é um projeto aberto de conhecimento clínico e regras para oncologia. Esta página coleta o material que costumava sentar-se em links de topo de menu separados: exemplos, especificações e GitHub.

O nosso objetivo

Tornar as decisões clínicas complexas mais fáceis de entender

O tratamento do câncer raramente tem uma única resposta óbvia. Os clínicos precisam considerar o diagnóstico, o estadio, os biomarcadores, o tratamento prévio e os riscos.

O OpenOnco tem como objetivo tornar esse processo visível: mostrar caminhos possíveis lado a lado, explicar o que influencia a escolha e link para fontes. Ele suporta preparação e discussão, em vez de prescrevê-lo automaticamente.

Uma simples regra

Uma reivindicação deve ser rastreável a uma regra e a uma fonte antes de poder se tornar parte de um plano.

A nossa abordagem

Um processo reprodutível para preparar uma conversa com um clínico

01

Estrutura do contexto clínico

O perfil descreve os fatos relevantes para a decisão: tipo de tumor, estágio, biomarcadores, condição geral e tratamento anterior.

02

Compare-o com regras e fontes

As regras usam uma base de conhecimentos versada, explicam por que uma opção é considerada, sem adivinhar um medicamento ou uma dose.

03

Resultados atuais que podem ser verificados

Os usuários vêem opções lado a lado, avisos e links para fontes originais, para preparar perguntas para um quadro tumoral ou oncologista.

O trabalho por trás dele

O principal esforço consiste em tornar os resultados bem apoiados

Uma base de conhecimento estruturada

The project maintainer records diseases, regimens, indications, warnings and sources as separate linked entities. Changes can then be versioned and checked, rather than getting lost in paragraphs.

Traçabilidade a cada passo

As alegações clínicas têm registrado a proveniência. Regras, resultados e exemplos públicos podem ser inspecionados em vez de tomados em confiança.

Segurança define os limites

The system does not replace diagnosis, handle emergencies, calculate personalised doses or make decisions on behalf of a clinician.

Avaliação local das regras

Plan Builder descarrega recursos públicos do motor e da base de conhecimentos e avalia as regras clínicas no navegador.

Processamento pelo servidor e fornecedor

Tumor Board envia o texto introduzido para o servidor API configurado e pode usar um fornecedor de modelos. Consulte as políticas do alojamento e do fornecedor; não envie dados que identifiquem pacientes.

Forma do projecto

Abrir por padrão

Código é estilo MIT; especificações e conteúdo gerado são CC BY 4.0.

Dados públicos sintéticos

The public site ships no real patient records and no patient-specific private artifacts.

Revisão clínica

O conteúdo clínico precisa de aprovação do revisor antes de se tornar conteúdo confiável.

Automação auditável

Regras, fontes e raciocínios tornados são visíveis em vez de escondidos atrás de uma caixa preta.
