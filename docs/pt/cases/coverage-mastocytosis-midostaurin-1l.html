O que NÃO fazer

Explicit prohibitive rules, each grounded in a regimen / supportive care / contraindication entity
Plano agressivo (IND-ADVSM-1L-MIDOSTAURIN)
  • NÃO utilize imatinib no KIT D816V SM avançado (resistência intrinsica) — o imainib está reservado para a rara neoplasia mielóide FIP1L1-PDGFRA com eosinofilia (entidade separada).
  • Do NOT continue midostaurin through gr ≥3 nausea/vomiting without antiemetic optimization + dose reduction (100 → 50 mg BID).
  • Do NOT start midostaurin without baseline ECG — QT prolongation requires electrolyte correction + monitoring.
Plano normalizado (IND-ADVSM-1L-AVAPRITINIB)
  • NÃO utilize imatinib no KIT D816V SM avançado — resistência intrínseca (choque esterístico).
  • Do NOT start avapritinib with platelets <50 ×10⁹/L — boxed warning; switch to midostaurin (alternative indication).
  • NÃO utilize avapritinib como monoterapia para o SM-AHN — o componente AHN (MDS/ CMLL/ AML) necessita de uma terapêutica direcionada para a histologia.
  • NÃO pule a RM cerebral basal — a vigilância com microsangue cerebral faz parte do esquema de monitorização.
