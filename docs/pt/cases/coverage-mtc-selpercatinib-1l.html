O que NÃO fazer

Explicit prohibitive rules, each grounded in a regimen / supportive care / contraindication entity
Standard plan (IND-MTC-ADVANCED-1L-SELPERCATINIB)
  • NÃO inicie a terapêutica sistêmica em calcitonina MTC assintomática, estruturalmente estável, de elevação lenta — observe com calcitonina / CEA q3-6 mo + imagem q6-12 mo.
  • NÃO utilize iodo radioactivo (IRA) no MTC — as células C parafoliculares não concentram iodeo; o IRA tem eficácia zero.
  • NÃO pule o teste de RET de germina — ~25% do MTC é hereditário; germline impulsiona positiva triagem em gênero + vigilância de feocromocitoma + tempo profilático-tireoidectomia em descendentes.
