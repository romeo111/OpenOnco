Definições métricas

  • #Bio — biomarcadores distintos referidos pelas indicações da doença + Regimens
  • # Drug — medicamentos distintos nos regimes desta doença
  • #Ind / #Reg / #RF — Indicações / Regimes / RedFlags para esta doença
  • 1L / 2L — Algorithm presence for first-line / second-line+
  • Quest — ✓ autoria manual / STUB auto-generado / — ausente
  • Preencher % — composite over 8 entity types: ≥1 indication, ≥1 regimen, ≥1 biomarker, ≥1 drug, ≥1 redflag, 1L algo, questionnaire, workup
  • Ver % — % das indicações desta doença com sinalização de revisor ≥ 2 (CARTER §6.1)
Ver % é principalmente 0% — isenção de certificação de modo dev (project_charter_dev_mode_exemptions) está em vigor até que as Co-Leads Clínicas sejam nomeadas. Isto é intencional, não um bug.
