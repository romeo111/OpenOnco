Resumo das provasBRAF V600E (e V600K) no melanoma cutâneo é o motor prototípico: a associação BRAF + MEK inibição (dabrafenib + trametinib; encorafenib + binimetinib; vemurafenib + cobimetinib) produz elevado ORR (~65- 70%) e melhora a SO versus BRAFi mono-agente (COMBI-d/ v, coBRIM, COLUMBUS). Adjuvante dabrafenib + trametinib melhora a RFS no estágio III (COMBI- AD). Triplote com anti-PD-1 (atezolizumab + vemurafenib + cobimetinib; IMspire150) estende a PFS por duplote.
