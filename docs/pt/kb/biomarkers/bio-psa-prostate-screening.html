Notas

Contexto de rastreamento para PSA — separado da BIO-PSA (que cobre a dinâmica de diagnóstico e tratamento-monitorização para o câncer de próstata estabelecido). USPSTF 2018: Grau C para homens 55-69 (compartilhação individualizada de decisão sobre benefícios + danos); Grau D para homens ≥70 (recomendar contra a triagem de rotina). NCCN 2025 (Detecção precoce): discussão basal de PSA + DRE aos 45 anos para homens afro-americanos ou portadores de BRCA2 (grupos de alto risco), idade 50 para risco médio; se PSA <1 ng/ml, repetir a cada 2-4 anos; se o PSA 1-3 ng /ml, repetir a cada 1-2 anos; Se o Psa >3 ng ou ml, avaliar mais adiante (repetir o Pssa, mpMRI, reflexo de biomarcador como 4Kscore/PHI, possível biópsia). Intensidade de triagem superior para portadores confirmados de linha germinativa BRCA2. (Estudo IMPACT — PSA q1y idade inicial 40; limiar de biópia ≥3 nG/ml). A PSA pode ser falsamente elevada em BPH, prostatite, retenção urinária, instrumentação recente. Razão de PSA livre, densidade de Psa e biomarcadores reflexos (PHI, 4Kscore, SelectMDx) reduzem biópsia desnecessária. Limitações: sobrediagnóstico/sobretratamento de cânceres indolentes (danos bem caracterizados — driver do grau C da USPSTF).
