Notas

A terapia multimodal agressiva é o padrão: ressecção cirúrgica máxima segura + quimioterapia intensiva adjuvante + (em pacientes > 3 anos que toleram) RT cranioespinal. Tazemetostat (inibidor de EZH2) é aprovado pela FDA para adultos recidivantes/refratários INI1- sarcoma epitelioide negativo + ATRT (dados pediátricos limitados). Vigilância para portadores de RTPS: RM no cérebro q3mo desde a infância até os 3-4 anos, depois q6mo até os 5 anos; RM no corpo inteiro q3-6mo até os 5 anos para detectar TRM extracraniana de rim + tecido mole.
