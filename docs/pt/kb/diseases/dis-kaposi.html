Capacidades

Notas

Quatro formas epidemiológicas (clássicas / endémicas / iatrogênicas / relacionadas com a AIDS) compartilham HHV-8 como etiologia vinculativa. Tratamento: restauração imune primeiro (ART para AIDs-KS; reequilíbrio imunossupressão para iatrogénica - conversão mTOR- inibidor tem atividade anti-Kaposi direta); quimioterapia sistêmica (doxorrubicina lipossómica / paclitaxel) para doença sintomática / visceral. A doença de Castleman multicêntrica (MCD) impulsionada pelo KSHV e linfoma de derrame primário (PEL) são entidades relacionadas, mas distintas.
