Notas

O leiomiossarcoma é um sarcoma de origem muscular lisa que ocupa ~15% do volume de sarcomas de tecido mole adulto. Esta entidade é autoriada como uma âncora de prevenção/herdeira para fluxos de trabalho de vigilância genética-síndrome (HCRCC, Li-Fraumeni); para o apoio geral à decisão de terapia sistêmica STS a entidade mãe DIS-SOFT-TISSUE-SARCOMA permanece a referência canônica, que trata o LMS como um dos vários subtipos histológicos. Três subconjuntos anatômicos com biologia distinta + contexto clínico: - Retroperitoneal / abdominal-pelvico LMS (~40%): muitas vezes surge de vena cava inferior ou grandes vasos; a cirurgia é modalidade principal; quimio-sensibilidade moderada (doxorrubicina-base 1L). - leiomiosarcoma uterino (uLMS, ~25%): pós-menopáusica; apresenta como massa uterina rapidamente alargada; muitas vezes diagnosticada errónea como leiomioma benigno. Histerectomia abdominal total + salpingo-ooforectomia bilateral para doença localizada; benefício quimio (LMS-02 / GeDDiS). uLMS tem uma âncora hereditária distinta (HCRCC, germinal FH). - Cutâneo + extremidade LMS (~25%): melhor prognóstico quando pequeno + superficial; ampla excisão local frequentemente curativa.
