Notas

Coverage-enabling local-therapy indication for DIS-PHEOCHROMOCYTOMA. Models surgery NARRATIVELY (via stage_requirements/rationale/do_not_do) rather than via the phases:/surgery_id mechanism used by the meningioma gold-standard example, because no Surgery/Procedure entity for laparoscopic or cortical-sparing adrenalectomy exists in the KB yet and creating one was outside the entity set this pass was scoped to (Algorithm/Indication/Regimen/Drug/RedFlag/Source only) -- flagged as a follow-up PR on the Disease file. recommended_regimen therefore points at the mandatory alpha-blockade regimen (REG-ALPHA-BLOCKADE-PREOP-PHEO), the actual drug-level component of this pathway, with the hard RF-PHEO-INADEQUATE-ALPHA-BLOCKADE gate carrying the sequencing rule. Requires endocrine surgery / anesthesiology co-lead signoff before clinical publication.
