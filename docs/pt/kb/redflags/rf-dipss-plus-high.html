Notas

DIPSS-Plus (Gangat 2011) estende DIPSS com plaquetas < 100K, dependência transfusional RBC, cariótipo desfavorável. int-2 / alto → mediana OS ~2,9 / 1,3 anos sem aloHCT. AlloHCT é a única modalidade curativa, mas 30-50% TRM em pacientes mais velhos. MIPSS70/MIPSS70+v2,0 são extensões moleculares mais recentes. Companheiro com RF-PMF-HIGH-RISK-DIPSS (existindo, gatilho semelhante): manteve-se como uma bandeira transversal separadamente nomeada usando a nomenclatura canônica risco-escore para que futuros shorts MDT possam alvo a pontuação nomeada diretamente.
