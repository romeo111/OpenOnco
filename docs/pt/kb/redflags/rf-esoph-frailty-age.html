Origem da bandeira vermelha

DefiniçãoFrailty profile precluding CROSS / FLOT / definitive CRT in esophageal: ECOG ≥3, OR (age ≥75 + Charlson ≥3), OR composite (age ≥70 + albumin <3.0 + ≥10% weight loss + sarcopenia). Triggers definitive RT-only (palliative-intent), best-supportive-care with palliative stenting + nutrition optimization.

Notas

O câncer esofágico afeta de forma desproporcionada os pacientes mais velhos; otimização nutricional pré-CROSS (PEG/J-tube) frequentemente necessária. Idosos frágeis: hipofracionados RT 30-40 Gy paliativos + stent para controle de disfagia.
