Origem da bandeira vermelha

DefiniçãoChild-Pugh B or C cirrhosis in HCC patient. CP-A is the only fully- studied class for ICI combinations (atezo+bev, durva+treme); CP-B has partial sorafenib/lenvatinib data but worse safety; CP-C generally precludes systemic therapy (focus on supportive care + transplant evaluation if liver-limited disease).

Notas

O escore Child-Pugh avalia encefalopatia, ascite, bilirrubina, albumina, INR. CP-B: ICI-bev contraindicado (estresse antiangiogênico no fígado descompensado); dados parciais de sorafenib (registro GIDEON). CP-C: melhor cuidado de suporte + hepatologia/transplante; quimioterapia sistêmica não indicada.
