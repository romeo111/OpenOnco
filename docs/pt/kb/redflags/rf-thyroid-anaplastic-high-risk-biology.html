Notas

A ATC é uma das mais agressivas malignidades humanas (mediana OS 3-6 meses historicamente).A descoberta de que ~25-40% são BRAF V600E- mutante transformado prática — dabrafenib + trametinib (roar cest) alcançado ORR ~70% com mediana OS estendido a ~14 mo em BRAF mutante ATC, às vezes converter irresecável para resecável. Recomendação NCCN Cat 1; aprovação FDA 2018. Para BRAF-mut ATC, neoadjuvante dabrafenib + trametinib → cirurgia → adjuvante RT é agora o paradigma ideal quando viável. NTRK / RET / ALK fusãos <5% combinados, mas altamente acionáveis. O perfil genômico abrangente dentro de dias do diagnóstico é crítico dado tempo de doença. Prioridade subiu para 30 porque a terapia direcionada é o reverso de nível crítico do padrão citotóxico.
