Notas

Standard 1L for fit-for-intensive AML. Add midostaurin if FLT3-ITD/TKD+ (RATIFY: improved 4-y OS 51% vs 44%). Day-14 BM check at end of induction; if blasts persist → re-induction. Consolidation HiDAC 3 g/m² q12h d1, 3, 5 for 3-4 cycles in young fit favorable / intermediate-risk; alloHCT for adverse-risk in CR1. STUB — requires clinical co-lead signoff before publication.
