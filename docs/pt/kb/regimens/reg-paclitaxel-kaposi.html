New Regimen entity reusing the existing DRUG-PACLITAXEL Drug entity. DRUG-PACLITAXEL already documents "Kaposi sarcoma (AIDS-related, 2L)" as an FDA-approved indication (regulatory_status.fda.indications_brief -- pre-existing fact, transcribed not invented, verified by direct read of drugs/paclitaxel.yaml during independent review) but its typical_dosing field does not carry a Kaposi-specific mg/m²/schedule figure, and no KB-verifiable primary source for that figure was available at authoring time. Per CHARTER §8.3 ("must NEVER invent a dose ..."), the `dose`/`schedule` component fields are deliberately left as an explicit flagged gap rather than a fabricated number -- this is an intentional, disclosed omission, not an authoring oversight. The mandatory Cremophor-EL hypersensitivity premedication IS transcribed from the existing DRUG-PACLITAXEL entity because that fact is dose-independent and already verified in the KB.
