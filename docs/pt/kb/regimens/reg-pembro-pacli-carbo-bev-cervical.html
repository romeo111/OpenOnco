Notas

KEYNOTE-826 backbone for metastatic/recurrent cervical cancer 1L. Carboplatin AUC 5 preferred over cisplatin in this setting (cisplatin often previously used in concurrent CRT). Bevacizumab addition: GOG-240 OS benefit (HR 0.71) + KEYNOTE-826 design — use when no fistula/hemorrhage history. Cisplatin alternative permitted: 50mg/m² if cisplatin-naive and renal function adequate (CrCl ≥60).
