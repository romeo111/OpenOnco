Notas

FIGHT-202 phase 2 (Abou-Alfa Lancet Oncol 2020; SRC-FIGHT-202): pemigatinib 13.5 mg PO daily 14d on/7d off in advanced/metastatic cholangiocarcinoma post-≥1L systemic therapy. Cohort A (FGFR2 fusion / rearrangement, n=107): ORR 35.5% (38/107), DCR 82%, mPFS 6.9 mo, mOS 21.1 mo. FDA accelerated approval Apr 2020; converted to traditional approval after confirmatory data. Class FGFR-TKI toxicity: hyperphosphatemia (~60-90%, class effect from FGF23 axis), serous retinopathy / RPE detachment, nail / hair / mucosal toxicity. Resistance: gatekeeper V564F and molecular-brake mutations; futibatinib (covalent FGFR1-4 TKI, FOENIX-CCA2) retains activity against some pemigatinib- resistance variants. STUB pending Clinical Co-Lead sign-off; SRC-FIGHT-202 currently a stub source — full citation pending.
