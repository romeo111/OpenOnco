Нотатки

Універсальний несприятливий маркер при більшості гематологічних і солідних злоякісних пухлин — передбачає погану відповідь на хімотерапію та хімоімунотерапію; відбирає для схем з новими агентами / цільовою терапією / клітинною терапією / алоТГСК. **Вплив на вибір терапії в нашій БЗ (поточний обсяг):** - **ХЛЛ/МЛЛ**: TP53-мут АБО del(17p) → протипоказання до хімоімунотерапії (FCR/BR); перевага фіксованій тривалості VenO (CLL14) над безперервним BTKi за деякими настановами. Закодовано в BIO-CLL-HIGH-RISK-GENETICS + RF-CLL-HIGH-RISK. - **МКЛ**: TP53-мут → передбачає невдачу хімоімунотерапії (результати інтенсивного R-CHOP/R-DHAP+аутоТГСК суттєво гірші); маршрутизація до BTKi-ГЦБ першої лінії (акалабрутиніб + R) незалежно від фізичного стану. Закодовано в RF-MCL-BLASTOID-OR-TP53. - **ММ**: del(17p) є частиною цитогенетичного комплексу високого ризику — визначає вибір квартету (D-VRd) над триплетом (VRd). Закодовано в BIO-MM-CYTOGENETICS-HR + RF-MM-HIGH-RISK-CYTOGENETICS. - **ДВКЛ** (майбутній напрям): передбачає невдачу R-CHOP; позначка для раннього розгляду CAR-T при 2L+.
