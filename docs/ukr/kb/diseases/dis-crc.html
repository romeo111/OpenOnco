Можливості

Нотатки

Об'єднана нозологія, що охоплює рак ободової та прямої кишки. Більшість рішень щодо системної терапії для обох локалізацій спільні (FOLFOX/CAPOX у ад'ювантному режимі; FOLFIRINOX, FOLFOX + бевацизумаб / цетуксимаб / паніт- у метастатичному; пембролізумаб у першій лінії при MSI-H), однак для прямої кишки додатково виникають рішення щодо неоад'ювантної хіміопроменевої терапії та TNT, які поточна схема не може коректно виразити (див. PROPOSAL §17). Наразі специфічна для прямої кишки неоад'ювантна логіка документована у вільному тексті полів Indication notes; повне впорядкування секвенування очікує ратифікації пропозиції. Обов'язкові біомаркери відповідно до NCCN colon v4.2025 §pretreatment для будь-якої III-IV стадії: MSI / dMMR (визначальний для лікування при MSI-H), розширений RAS (KRAS екзони 2-4 + NRAS екзони 2-4), BRAF V600E, HER2 (рідкісний, але актиабельний у RAS-WT).
