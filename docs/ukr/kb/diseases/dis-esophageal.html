Можливості

Нотатки

Скафолд для Phase GI-1: один червоний прапор (дисфагія / аспірація високого ступеня — найчастіша гостра форма звернення), одне показання (скафолд CROSS-типу зі застереженням, що променева терапія не моделюється), один алгоритм. Повний гістологія-стратифікований алгоритм (плоскоклітинний рак: дефінітивна хіміопроменева терапія для нерезектабельних, CROSS для резектабельних; аденокарцинома: FLOT як препаратний вибір для резектабельних, CROSS як альтернатива) + ад'ювантний ніволумаб (nivolumab) після CROSS без досягнення pCR + біомаркер-стратифіковані комбінації імунотерапії та хіміотерапії для метастатичної форми очікують ратифікації пропозиції та клінічного авторства. Гістологічне розгалуження є критичним — плоскоклітинна та аденокарциномна гілки мають значною мірою паралельні, але частково розбіжні парадигми лікування. Допускається окреме викладення в одному YAML захворювання з полем гістології на рівні застосовності Indication.
