Можливості

Нотатки

HCC є канонічним прикладом "гібридного" архетипу: стадія за BCLC визначає модальний каскад (резекція / трансплантація / абляція для 0-A; TACE / TARE для B; системна терапія для C; паліативна допомога для D), а етіологічні фактори керують паралельними рішеннями (профілактика реактивації HBV при ICI / хіміоемболізації; лікування HCV із досягненням SVR; модифікація способу життя при MASH; припинення вживання алкоголю). Клас за Child-Pugh є універсальним модифікатором — кожна стадія BCLC має підрозділ CP-A, CP-B та CP-C, причому CP-C загалом виключає системну терапію. Цей комміт постачає лише логіку системної терапії (BCLC C, CP-A); курабельні модальності (хірургія, трансплантація, абляція) очікують ратифікації PROPOSAL §17, тому нозологія позначена як `partial`.
