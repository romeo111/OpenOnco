Можливості

Нотатки

Скафолд для Phase GI-1: один червоний прапор (біліарна обструкція / холангіт — найчастіша гостра декомпенсація), одне показання (FOLFIRINOX у першій лінії метастатичної терапії як найбільш застосовний скафолдний варіант), один алгоритм. Стратифікація для резектабельної / пограничної / місцево-поширеної форми, а також ад'ювантний mFOLFIRINOX з підтримкою олапарибом (olaparib) при BRCA — очікують ратифікації пропозиції та клінічного авторства. Ключові біомаркери: герміногенні BRCA1/2 + PALB2 (POLO — олапариб у підтримці), MSI/dMMR (~1% — рідкісний, але пацієнти підлягають пембролізумабу (pembrolizumab)), KRAS G12C (рідкісний — ~1-2% PDAC, ємний клас соторасибу (sotorasib)).
