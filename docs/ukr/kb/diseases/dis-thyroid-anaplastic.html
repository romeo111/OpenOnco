Нотатки

Історично — серед найбільш летальних солідних пухлин: за AJCC будь-яка ATC при встановленні діагнозу класифікується як IV стадія (будь-яке T, будь-яке N, M0/M1 = stage IVA/B/C). Медіана загальної виживаності без таргетної терапії — 3-6 months; характерна швидка компрометація дихальних шляхів. Часово-критичне обстеження: перша лінія системної терапії визначається статусом BRAF V600E, тому результат має бути доступним у межах днів, а не тижнів. Настанови ATA 2021 вимагають швидкого IHC (з антитілом VE1) з рефлекторним секвенуванням. Терапія за генотипом: - BRAF V600E мутантний (~25–40%): дабрафеніб (dabrafenib) + траметиніб (trametinib) (basket-дослідження ROAR — ORR ~56%, трансформаційний результат); схвалення FDA для ATC у 2018 році. Часто застосовують у неоад'ювантній індукції з подальшою хірургією та ад'ювантною хіміопроменевою терапією. - BRAF wild-type з таргетним RAS / NTRK / RET: селперкатиніб (selpercatinib) / пралсетиніб (pralsetinib) / ларотректиніб (larotrectinib) / ентректиніб (entrectinib) — за генотипом. - BRAF/RAS/NTRK/RET wild-type: хіміопроменева терапія (паклітаксел (paclitaxel) + променева терапія або доцетаксел (docetaxel) + доксорубіцин (doxorubicin) + променев...
