Нотатки

MSI-H (dMMR) КРР — ~15% всіх стадій, ~5% мМСС. Пембролізумаб 1L мМСС: KEYNOTE-158 + KEYNOTE-177 — ЗВ ~>50% при 2 роках, ЗВБп 16 проти 8 міс; FDA-схвалено. Ніволумаб + іпіліму маб (CheckMate-142) — альтернатива 1L. Усі стадії: дефіцит MMR (MLH1, MSH2, MSH6, PMS2 по ІГХ або MSI-H по NGS) скринінг синдрому Лінча — випадки, обумовлені синдромом Лінча потребують генетичного консультування родини. dMMR неметастатичний КРР: пембролізумаб неоад'ювантний у випробуваннях (NICHE-2 — ЗПП 67%). СТАБ — потребує підпису клінічного співкерівника.
