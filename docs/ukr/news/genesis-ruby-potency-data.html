20 листопада 2026 startup drug-discovery open-data evidence

Genesis відкриває дані про активність молекул; користь Ruby для пацієнтів ще не доведено

Відкритий набір містить 5 410 616 записів із походженням джерел. Тести Ruby оцінюють лабораторні прогнози, а не результати лікування раку.

— OpenOnco

Написано ретроспективно, опубліковано 23 листопада 2026.

Повідомлення компанії не є незалежним доказом клінічної користі. Це інформаційне порівняння, а не медична порада. Цей матеріал не замінює консультації лікаря.

20 листопада 2026 року Genesis Molecular AI представила Ruby — модель для прогнозування активності малих молекул щодо білкових мішеней — і відкрила частину даних для її навчання. Публічний набір GenesisPotency-2026 має ліцензію CC BY-SA 4.0 та пов’язує вимірювання із записами ChEMBL, BindingDB або PubChem. У README зазначено 5 410 616 записів, тоді як у повідомленні про запуск — 5,6 млн. Набір можна завантажити безкоштовно; репозиторій не містить ваг моделі Ruby чи публічної ціни її використання.

За даними Genesis, Ruby досягла середньої кореляції Спірмена 0,61 у восьми аналізах із п’яти програм розробки ліків Genesis та Incyte, не маючи попередніх вимірювань із цих аналізів. Це оцінка самої компанії разом із публічними тестами, а не незалежне клінічне дослідження. Прогноз активності молекули може допомогти дослідникам вибрати сполуки для перевірки, але не доводить, що препарат лікує рак у людей. README прямо застерігає: набір не призначений для клінічних чи діагностичних рішень.

OpenOnco доступний безкоштовно та публікує код за ліцензією MIT, перевірювані правила й онкологічні знання з джерелами для чернеток за вигаданими випадками. Він не прогнозує активності молекул щодо білків і не розробляє нових ліків. Відкриті дані аналізів Genesis і знання OpenOnco з посиланнями на джерела потрібні на різних етапах досліджень і допомоги; прямого порівняння точності чи результатів для пацієнтів немає. Джерела перевірено 23 листопада 2026 року. Матеріал не замінює лікаря.
